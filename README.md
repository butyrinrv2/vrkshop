## 🎮 Что такое VRKShop?

**VRKShop** — это VR-песочница в стиле мастерской и строительства, где игрок физически взаимодействует с инструментами и материалами.

В игре можно:

- Пилить дерево
- Колоть древесину
- Забивать гвозди
- Вручную строить различные конструкции
- Использовать инструменты виртуальной мастерской
- Физически взаимодействовать с материалами и окружающим миром

Главная особенность игры — физическое взаимодействие с предметами своими руками, а не упрощённая система строительства через меню.
